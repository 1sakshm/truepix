Smaller than JPEG XL. Every pixel exact.

Truepix is a lossless image codec for archives. On 24 photos it had never seen, JPEG XL at its top effort came out 3.62% larger, and Truepix won on every one. The price is slow decoding.

Decoding takes about 100 times longer than JPEG XL

Truepix does all of its modelling again to decode, so opening a photo takes seconds. That rules out web pages and suits archives, where a file is written once and rarely read.

How a pixel gets coded

Truepix works through each sample in order, and the decoder repeats the same steps to stay in step with it.

  1. PredictFour least-squares predictors and eleven simple ones guess the next value, and an adaptive blend combines them.
  2. CorrectBias cancelling removes the errors the blend keeps making in similar places.
  3. Model21 contexts estimate each bit, including exact colour differences that can learn a colour grid with no formula.
  4. MixFive small neural mixers and a final one weigh those estimates, then two adaptive maps refine the result.
  5. CodeA 32-bit binary arithmetic coder turns the final probabilities into bytes.

What the Kodak benchmark was hiding

A slow general compressor, paq8px, beat image codecs by a surprising margin on the famous Kodak test set. About 90% of that gap was colour. Kodak's images came from Photo CD, so their RGB values sit on a stretched integer grid. Only 12.8% of all RGB colours can occur on it, and those colours hold 87.3% of Kodak's pixels.

Exact-difference contexts turned that finding into a gain for ordinary images too. On Kodak itself, Truepix reaches 5.723 bits per pixel. It was tuned on those images, so that isn't a fair score.

The same file on every build

Encoder and decoder must agree on every bit of floating-point maths. Files were byte-identical across seven builds using GCC, Clang, 32-bit x86 and WebAssembly, and all 245 cross-build decodes came back exact.

What it doesn't do

  • paq8px still compresses further. On the tuning crops it was about 5% smaller on green and 7% smaller on colour, and it is far slower.
  • Pixels only. Colour profiles and other metadata are not stored.
  • 8-bit images only. Grey or RGB, with or without alpha. Anything else is refused.
  • ARM is untested. It compiles for ARM64 but has never been run there.
  • Nobody else has checked this yet. The results have not been independently replicated.
  • The file format may change. Keep your originals for now.

Use it

Truepix is a C++ codec with a small Python command-line tool. The source isn't public yet.

g++ -std=c++17 -O3 -mavx2 -ffp-contract=off -static truepix-core.cpp -o truepix-core.exe

uv run truepix compress photo.png --verify   # writes photo.tpix
uv run truepix decompress photo.tpix         # writes photo.png

The full method, every result and its limits are in the paper (PDF).
